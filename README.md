## About the course

Learners set up a company in Xero with bank accounts and a chart of accounts, import master data, process quotations, invoices, purchase orders, bills and credit notes, apply Singapore GST to expenses and invoices, and generate the reports an SME needs. All activities follow Lumina Homeware Pte Ltd, a fictional Singapore SME; every name and financial record is mock data for training only.

## Learning outcomes

- **LO1:** Configure and import relevant data to the Xero accounting system.
- **LO2:** Input and control day-to-day sales, purchasing, banking and inventory data in Xero.
- **LO3:** Compute and review GST for expenses and invoices using appropriate Singapore tax rates.
- **LO4:** Generate and interpret financial, accounting, ageing and GST reports for SME decisions.

## Topics covered

1. Introduction to Xero Accounting System
2. Input Data to Xero
3. Manage Goods and Services Tax (GST)
4. Financial and Accounting Reports
